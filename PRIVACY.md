# TabWake Privacy Policy

TabWake is a local-first browser extension. It has no account system, no backend server, and no remote sync. It does not collect, transmit, sell, or share user data. Everything it stores stays in the local browser profile.

Each browser store has its own policy, covering that browser's permission model and store requirements:

- **Google Chrome** — [docs/privacy-policy-chrome.md](docs/privacy-policy-chrome.md)
- **Microsoft Edge** — [docs/privacy-policy-edge.md](docs/privacy-policy-edge.md)

## In short

- Saved site names, URLs, rules, settings, and local run records live in browser extension storage.
- Import and export use local JSON files that the user chooses; nothing is uploaded.
- The only network requests come from the optional Auto-update feature, go directly from the user's browser to the site the user configured, and happen only when a rule is triggered.
- No analytics, ads, tracking, remote code, or third-party data processors.

For support or privacy questions, open an issue at <https://github.com/RT64M/TabWake/issues>.
